## What it does

`main.py` writes a single letter to `/output/entry.txt` — exactly one
character, nothing else:

> Z

The letter stands for "zero sleep": a day of nonstop building, from the
first commit in the morning to the last one past midnight, with no sleep
in between. One letter carries the whole day.

## Run it

```sh
python3 main.py
```
